# Performance report

Generated by Tools > S3 > Performance Test (`ArtPerfTest.cs`). Each run: 2 s warm-up, then 10 s of samples.
Measured in **Editor Play mode**: editor overhead is included, so a standalone build is usually faster.
No animation clips yet: birds are static, but every SkinnedMeshRenderer is still skinned each frame.
Note: in the two 11 Oct 12:57 / 12:58 runs the "CPU main thread" and "Render thread" rows are in **seconds** (0.01 s ≈ 10 ms), a unit bug fixed afterwards. Use "Average frame time" for those runs.
Note: in the runs up to 13 Oct 20:24 the row "CPU main thread (ms)" is the Stats panel value: the main thread's time for the whole frame, **including its wait for the render thread and the GPU**. It does not show whether the CPU or the GPU limits the frame. Later runs name it "Stats panel main thread, waits included" and add the "Frame timing" rows (FrameTimingManager), which split that time.
