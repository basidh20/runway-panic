## 2026-10-17 — to: Systems Engineer — BirdHealth implements IDamageable (your 16 Oct request)
- **What:** `Scripts/Agents/Shared/BirdHealth.cs` on every bird prefab root
- **Details:**
  - **Taking hits:** `TakeDamage(amount, rarity)` uses `species.GetDamageTaken(amount, rarity)`, so the wrong gun does 10%. HP comes from `species.MaxHP`.
  - **Collider:** the hit collider is the root `CapsuleCollider`, so `GetComponentInParent<IDamageable>()` in `PlayerShooting` finds it.
  - **On a hit:** plays the flinch (Hit trigger, Reactions layer); the bird keeps flying.
  - **Events:** `Damaged(float damageApplied, float hpAfter)` on every hit; `Died(BirdHealth)` once, plus the static `BirdRegistry.BirdDied`.
  - **On death:**
    - plays Death, then calls `CoinManager.Instance.AddCoins(species.CoinReward)` (null-checked);
    - stops the motor and lets the body fall with its momentum;
    - on landing it turns kinematic and drops its collider (no more hits, the player can walk over it);
    - after 2 s it is **destroyed**, or deactivated if `cleanup` is set to Deactivate (pooling).
  - **Also available:** `Kill()`, `Revive()` (pooling, tests), `MaxHP`.
  - **Bird attacks:** `BirdContactAttack.TryAttack()` damages the player with `playerHealth.TakeDamage(species.AttackDamage, WeaponRarity.Common)`, as you specified. Range is measured to the player's collider; the cooldown is `AttackCooldown`.
- **Action needed:** none. The Eagle → Gull rename and gun re-map requested in `Docs/IS/HANDOFF.md` is yours; nothing in my code depends on the enum order.
- **Status:** done
